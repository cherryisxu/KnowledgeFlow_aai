# Python 列表基础

Python 列表（List）是 Python 中最常用、最基础的有序、可变序列数据结构。它可以同时存储不同类型的元素（数字、字符串、列表、字典等），就像一个多功能的“容器”，能灵活存放、修改、管理一组数据，是编程中处理批量数据的核心工具。

## 一、列表的创建

创建列表非常简单，使用方括号 `[]` 包裹元素，元素之间用英文逗号 `,` 分隔即可。也可以使用 `list()` 函数创建空列表或转换其他可迭代对象为列表。

列表的核心特性：**有序**（元素有固定的先后顺序）、**可变**（可随时增删改元素）、**允许重复元素**。

## 二、访问列表元素

列表是有序的，每个元素都对应一个**索引**（下标），索引从 **0** 开始计数，通过索引可以精准获取、修改元素。

## 三、列表的核心添加元素方法

添加元素是列表最常用的操作之一，根据需求不同，分为**末尾添加单个元素**、**末尾添加多个元素**、**指定位置插入元素**三种场景。

### 1. append()：末尾添加单个元素

`append()` 方法专门用于向列表**末尾添加一个元素**，是最基础的添加方式，不会改变原有元素的顺序，执行效率高。

### 2. extend()：末尾添加多个元素

如果需要一次性向列表末尾添加**一组元素**（多个元素），使用 `extend()` 方法。它会将传入的可迭代对象（列表、元组等）拆分为单个元素，逐个添加到原列表末尾。

### 3. insert()：指定位置插入元素

如果需要在列表**任意位置**插入元素，使用 `insert(索引, 元素)` 方法。插入后，该位置之后的元素会自动向后顺延。

## 四、列表的删除元素方法

列表的可变特性不仅支持添加，还支持灵活删除，常用删除方法有 4 种：

1. `del 列表[索引]`：根据索引删除元素。
2. `pop()`：删除并返回指定索引的元素（默认删除最后一个）。
3. `remove(元素值)`：根据元素值删除第一个匹配项。
4. `clear()`：清空列表所有元素。

## 五、列表的切片与常用操作

除了增删改，列表还支持**切片**（获取子列表）、长度统计、元素查找等实用操作。

# 1. 切片：列表[起始索引:结束索引:步长]（不包含结束索引元素）

print(fruits[1:4]) # ["banana", "orange", "grape"]（索引 1-3）

## 六、列表的遍历

处理列表数据时，经常需要逐个访问元素，使用 `for` 循环可以轻松遍历列表。

Python 列表的灵活性让它成为处理批量数据的首选。掌握创建、访问、增删、遍历等基础操作，是学习 Python 数据处理的第一步。后续结合排序、查找、嵌套列表等进阶用法，能应对绝大多数日常编程场景。

## 七、总结

1. 列表用 `[]` 创建，有序、可变、支持多类型元素，索引从 0 开始。
2. 增元素：`append()`（末尾单个）、`extend()`（末尾多个）、`insert()`（指定位置）。
3. 删元素：`del`、`pop()`、`remove()`、`clear()`，适用场景不同。
4. 可通过切片、遍历灵活操作列表，是 Python 最实用的基础数据结构。
